# 桌牌產生器

貼上姓名與職稱，預覽後下載可直接列印的 **A4 桌牌 PDF**。支援二折、三折、四折式。

純靜態網頁，沒有後端：所有處理都在瀏覽器本機完成，**名單不會上傳**到任何地方。

## 功能

- **匯入名單**：貼上 Excel 複製的兩欄（Tab 分隔），或用空格、逗號分隔，每行一人；也能匯入 CSV（UTF-8 或 Big5 都讀得到）。匯入後名單可直接編輯、刪除；同一人要印兩份就放兩次
- **折數**
  - 二折式：每格 148.5mm，一反一正
  - 三折式：每格 99mm，一反一正，最下格留白當黏合底
  - 四折式：每格 74.25mm，一張 A4 放連續兩人（人數是單數時，最後一張只放一人）
  - 每個桌牌的「反面」是旋轉 180°，以折線與「正面」對稱
- **版面**
  - 姓名預設在格子正中央，字級不影響職稱位置；姓名位置也可選「自訂」，用滑桿從置中位置往左右、上下移動（反面會自動跟著對稱移動；移到紙邊或格子邊界外會被限制在範圍內）
  - 職稱位置：靠左／置中／靠右，或「自訂」用滑桿調左右（可選以職稱中心、左緣或右緣為基準）與上下位置
  - 姓名、職稱字級與字距可全域調整，名單裡每個人也能單獨覆蓋字級
  - 字型：**全字庫正楷體（內建，預設）**、標楷體、微軟正黑體、新細明體。內建的全字庫正楷體跟標楷體風格非常接近，而且所有裝置（包含沒有標楷體的手機）看到、印出的都一樣；其餘三種使用裝置上的系統字型
  - 太長時預設自動縮小；字被縮小、或姓名與職稱重疊時，名單前會標 ⚠ 並在預覽下方說明
- **輸出**：「下載 PDF」以 300dpi 把每張 A4 畫成圖片再組成 PDF，檔名 `桌牌_年月日.pdf`。折線（虛線）與裁切線（實線，僅四折式兩個桌牌中間那條）可分開勾選要不要印
- **設定記憶**：折數、字級、位置等設定會記在瀏覽器的 localStorage；**名單不會被儲存**，重新整理就清空

## 注意事項

- PDF 裡的文字是圖片，不能選取或修改；要改請回網頁調整後重新下載
- **內建字型**「全字庫正楷體」涵蓋 Unicode 基本字面（BMP）約 2.7 萬個漢字，包含「堃」「喆」「峯」等常見的人名用字；更罕見的字（Unicode 第 2 字面以上）不在內，會改用裝置上的字型並在名單前標 ⚠ 提醒。字型被切成很多小檔，瀏覽器只下載名單裡用到的字所在的那幾片（每片約 40～80 KB）
- 其餘三種字型使用裝置上的**系統字型**。Windows 有標楷體，Mac 會改用 BiauKai／Kaiti TC；裝置沒有所選字型時，網頁會提醒，預覽與 PDF 會改用備用字型，印出來的樣子會不同

## 專案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構 |
| `style.css` | 樣式（含深色模式，跟隨系統） |
| `app.js` | 全部邏輯：版面計算、canvas 繪製、名單、設定記憶、PDF 輸出 |
| `vendor/pdf-lib.min.js` | [pdf-lib](https://pdf-lib.js.org/) 1.17.1（MIT 授權，授權文字見 `vendor/pdf-lib.LICENSE.md`），自行放在專案裡，不從外部網站載入 |
| `fonts/twkai/` | 全字庫正楷體的網頁切片（`*.woff2`）與 `twkai.css`，由 `tools/build_twkai_slices.py` 產生；出處與授權見 `NOTICE.md` |
| `tools/build_twkai_slices.py` | 把官方 `TW-Kai.ttf` 切成網頁字型切片的腳本（需要 `pip install fonttools brotli`；原始字型到 [data.gov.tw 資料集](https://data.gov.tw/dataset/5961) 下載 `Fonts_Kai.zip`） |
| `NOTICE.md` | 第三方內容的授權與顯名聲明（字型、pdf-lib），**重新散布時必須保留** |
| `vercel.json` | 安全標頭：CSP 只允許自己網域的檔案（沒有任何內嵌程式與外部資源）等 |
| `favicon.svg` | 網站圖示 |

## 部署

靜態網站，沒有建置步驟。已設定為推送到 `main` 後由 Vercel 自動部署。

本機預覽（需要 Python）：

```
python -m http.server 8000
```

然後開 http://localhost:8000。注意這樣不會套用 `vercel.json` 的安全標頭；要驗證 CSP 請以部署後的網址為準。

## 修改程式的注意事項

- 因為 CSP 是 `script-src 'self'; style-src 'self'`，**不能**寫內嵌 `<script>`、`<style>` 或 `style="..."` 屬性；要加樣式請寫進 `style.css`，用 JS 設 `element.style.xxx` 是可以的
- 預覽與 PDF 輸出共用 `drawSheet()`，改版面只要改這一處
